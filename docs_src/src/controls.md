# Key Reference

## Everywhere

| Key | Action |
| --- | --- |
| Tab / Shift+Tab | Next / previous stop |
| Arrows | Move within the stop |
| Home / End | First / last item of the stop |
| Ctrl+Up / Ctrl+Down | Previous / next region (a journal issue, a run-log cycle) |
| Enter | Activate |
| Backspace | Context menu (the game's right-click) |
| Shift+Backspace | Details of the focused item |
| Escape | Back, cancel or close |
| Page Up / Page Down | Sliders: large step |
| F6 | Typing echo on / off |

## Reactor and pipeline

| Key | Action |
| --- | --- |
| Ctrl+arrows | Skip cells that read the same as this one |
| Alt+1 | Jump to the grid or map. From a building's row in the pipeline's table: that building on the map |
| Alt+\` | Pipeline: jump to the components table. From a building on the map: its row |
| Alt+2 | Jump to the palette or shelf (Reactor Controls during a defense run) |
| Alt+3 | Jump to the tools |
| Alt+4 | Jump to the run log |
| Alt+5 | Jump to the layers (reactor) or the enemy (defense levels) |
| Alt+Backspace | Back to where you were before the last jump; again to return |
| Ctrl+1 to Ctrl+9 | Switch to that reactor in the pipeline |
| Ctrl+Tab / Ctrl+Shift+Tab | Switch to the next / previous reactor in the pipeline |
| [ / ] | Previous / next category |
| , / . | Previous / next item of the category; moves the cursor to it |
| C | Coordinates |
| M | The molecule of the reactor zone under the cursor, or of the pipeline port |
| Ctrl+S | Cycles, symbols and reactors so far |
| Ctrl+G | Level progress |
| Ctrl+Q | Reactor quota (levels with a pipeline) |
| P | Pipeline: the pipe being drawn, or the pipe under the cursor: its open end or what it connects to, and during a run how many molecules are in it |
| Shift+Space | Mark a rectangle corner; again on the opposite corner to finish. While the cursor is inside it, Delete, cut and copy act on the whole rectangle |
| Ctrl+A | Mark the whole grid |
| Ctrl+Space | Clear the mark |

## Running

| Key | Action |
| --- | --- |
| 1 / 2 / 3 / 4 | Run at speed 1 to 4 |
| Space | Run / pause |
| Backquote | Stop |
| 0 | Step to the next event of the open reactor |
| Ctrl+0 | Step to the next event of any reactor |
| 5 to 9 | Extra step keys, unassigned until set up in Settings, Mod tab, Step keys |
| F1 to F4 | Defense levels, during a run: toggle control A to D |

## Reactor: reading

| Key | Action |
| --- | --- |
| Shift+R / Shift+B | Red / blue waldo: its start when stopped; cell, heading, holding and waiting while running |
| Ctrl+Shift+R / Ctrl+Shift+B | The same, and jump the cursor to the waldo |
| Ctrl+R / Ctrl+B | The red / blue waldo's path as a list |
| Ctrl+T | Repeat the tutorial step |
| Alt+A / Alt+B | The alpha / beta input |
| Alt+P / Alt+O | The psi / omega output |
| Alt+Shift+A / B / P / O | Open that input's or output's molecule |
| Ctrl+Shift+P / Ctrl+Shift+O | Production levels: edit the psi / omega output's note |

## Reactor: placing and removing

| Key | Action |
| --- | --- |
| Q W E R T Y U I, A S D F G H J K | Place that palette slot's instruction at the cursor, in the active colour |
| L | Switch the active colour |
| Delete, Ctrl+X / Ctrl+C / Ctrl+V | Act on the active colour's instructions only. Hardware moves only by cut and paste, and only from a cell where the active colour has nothing (lock a layer to reach hardware under instructions) |

## Reactor: changing an instruction

| Key | Action |
| --- | --- |
| ' / ; | Next / previous value of the main setting: input or output type, grab type, bond type, direction, control letter, rotation |
| Shift+Up / Shift+Down | Choose which instruction in the cell to change |
| Shift+Left / Shift+Right | Choose the other colour's instructions, for this cell only |
| Alt+Up / Alt+Down | Choose a setting: colour, direction, grab type and so on |
| Alt+Left / Alt+Right | Change that setting |

## Pipeline map: zoom

| Key | Action |
| --- | --- |
| Shift+Up / Shift+Down | Zoom out / in: 1 by 1, 4 by 4, 8 by 8 |
| Ctrl+Shift+Up / Ctrl+Shift+Down | Straight to 8 by 8 / back to 1 by 1 |
| Arrows, Home / End | Next block; first / last block of the row |
| Ctrl+arrows | Skip blocks that read the same as this one |
| C | The block's range |
| Shift+Backspace | The block in detail: where each pipe runs through it, and which cells are free |
| Enter | Place the armed building at the block's top-left corner |
| Delete, Ctrl+X / Ctrl+C | Act on every movable building wholly inside the block (or on the marked rectangle, when the cursor is in it) |
| Ctrl+V | Paste at the block's top-left corner |
| Shift+Space | Mark the whole block; again in another block to stretch the mark over both |
